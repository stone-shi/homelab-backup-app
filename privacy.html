homelab-backup privacy policy

Last updated: 2026-11-09

homelab-backup is a personal tool used only by its owner, Stone Shi, to back up the owner's own files to the owner's own Google Drive account.

What the app accesses

With the owner's consent it uses the Google Drive scope drive.file, which only allows access to files and folders that the app itself created. It cannot see other files in the Drive account.

What is collected, stored and shared

  • The developer operates no server and receives no data from the app.
  • Backup contents go only from the owner's server to the owner's Google Drive, encrypted before upload.
  • The OAuth token is stored only on the owner's server, readable by the administrator.
  • No data is sold, shared with third parties, used for advertising, or used to train any model.

Revoking access

The owner can revoke access at any time in the Google Account's third-party access settings, and delete the backup folder from Google Drive.
